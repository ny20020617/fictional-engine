# あんスタ好き顔9選

スマートフォン向けの静的Webサイトです。GitHub Pagesでそのまま公開できます。

## 1. ローカルで確認
`index.html` をブラウザで開くだけで動作します。

## 2. キャラクター画像について
`images/` のSVGは公開用の仮画像です。
公式画像・カード画像を無断転載せず、権利関係を確認した画像に差し替えてください。

差し替える場合は、`images/` 内のファイル名を `script.js` のIDと一致させます。
例:
`images/hokuto.svg`

## 3. GitHub Pagesで公開
1. GitHubで新しいRepositoryを作成
2. このフォルダの中身をRepository直下へアップロード
3. Settings → Pages
4. Build and deployment の Source を「Deploy from a branch」
5. Branch を `main` / `/(root)` にして Save
6. 数分後に公開URLが発行されます
